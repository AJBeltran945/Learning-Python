Project 1 — Personal Expense Tracker 💰
Difficulty: Beginner
Concepts: Variables, data types, basic syntax, type casting, conditionals, built-in functions.

Build a command-line application that allows users to track their personal expenses.

Imagine running the program and seeing a menu like this:
=================================
       EXPENSE TRACKER
=================================

1. Add expense
2. View all expenses
3. Calculate total expenses
4. Show highest expense
5. Exit

Choose an option:

Features to implement
Version 1: Basic functionality
- Ask the user for their monthly budget.
- Allow them to enter an expense name and amount.
- Display all registered expenses.
- Calculate the total spent.
- Calculate the remaining budget.
- Warn the user if they exceed their budget.
Version 2: Additional functionality
- Categorize expenses, such as food, transport, and entertainment.
- Calculate the average expense.
- Display the cheapest and most expensive expenses.
- Allow users to search for expenses by name.
Python concepts you'll practise
Concept	Practical application
Variables	Store the budget and expense amounts.
Data types	Work with strings, integers, floats, and booleans.
Basic syntax	Write statements, comments, and expressions.
Type casting	Convert user input into numerical values.
Conditionals	Check whether the budget has been exceeded.
Loops	Keep the application running until the user exits.
Built-in functions	Use print(), input(), type(), sum(), min(), and max().
Functions	Create functions for adding expenses and calculating totals.
Lists	Store multiple expenses.


Example challenge: What happens if the user enters "twenty" instead of 20 as an expense?

Your program should handle the invalid input without crashing. You'll eventually use exceptions to solve this.

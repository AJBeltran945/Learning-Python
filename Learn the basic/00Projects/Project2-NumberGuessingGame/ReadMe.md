Project 2 — Number Guessing Game 🎮
Difficulty: Beginner
Concepts: Conditionals, loops, type casting, exceptions, built-in functions.

This project is smaller than the others, but it's excellent for learning how programs make decisions and repeat operations.
Features to implement
1. Generate a random number between 1 and 100.
2. Ask the player to guess the number.
3. Tell the player whether their guess is too high or too low.
4. Count the number of attempts.
5. End the game when the player guesses correctly.
6. Allow the player to restart the game.
Example
=================================
       NUMBER GUESSING GAME
=================================

I'm thinking of a number between 1 and 100.

Your guess: 50

Too high! Try again.

Your guess: 25

Too low! Try again.

Your guess: 37

Congratulations! You guessed the number in 3 attempts.

Python concepts you'll practise
Concept	Practical application
Variables	Store the secret number and number of attempts.
Data types	Work with integers, strings, and booleans.
Conditionals	Compare the player's guess against the secret number.
Loops	Repeat the guessing process.
Type casting	Convert the player's input to an integer.
Exceptions	Handle input that cannot be converted to an integer.
Functions	Separate the game logic into reusable functions.
Built-in functions	Use print(), input(), int(), and range().


You'll also learn to use Python's random module.
Additional challenges
Once the basic game works, try implementing:
- Three difficulty levels.
- A maximum number of attempts.
- A scoring system.
- A high-score tracker.
- A replay option.
- Input validation that rejects numbers outside the permitted range.
Important: Don't start by implementing everything. First, make a working game. Then add features individually.
